# مِشكاة الحديث

منصة عربية RTL للبحث في الأحاديث النبوية الموثقة، عرض الترجمات المعتمدة، وتحويل النص إلى تصاميم جاهزة للنشر دون السماح بتحرير نص المصدر.

## الوظائف المنفذة

- بحث مباشر عبر HadeethEnc API.
- جلب تفاصيل الحديث بالعربية وترجمته حسب اللغة المختارة.
- إظهار الراوي، الدرجة، المراجع، الشرح، ورابط المصدر.
- معاينة فورية بمقاسات 1:1 و4:5 و9:16.
- قوالب لونية متعددة، إظهار/إخفاء QR، وحفظ محلي للحالة.
- تصدير التصميم كصورة PNG عالية الدقة.
- واجهة متجاوبة للحاسوب والجوال، ودعم الحركة المخفّضة.

## التشغيل

```bash
npm install
npm run dev
```

اختبارات الإصدار:

```bash
npm run build
npm run test:sites
```

## سياسة المحتوى

يلتزم المشروع بشروط HadeethEnc: عدم تعديل المحتوى، إظهار المصدر بوضوح، حفظ معلومات النسخة والمراجع، ومزامنة المحتوى مع أحدث إصدار متاح. التخصيص البصري منفصل عن النص الموثّق.
